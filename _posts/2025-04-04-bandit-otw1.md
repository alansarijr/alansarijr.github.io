# Introduction

In Level 1, you are already connected to the Bandit server. Your task is to find the password for the next level stored in a file called `-` in the home directory.

# Task

Read the file named `-` in the home directory to get the password for Level 2.

**Login:** `ssh bandit1@bandit.labs.overthewire.org -p 2220`  
**Password:** *(retrieved from Level 0)*

# Theory

## Why is `-` special?

In most Linux commands, a single dash `-` is interpreted as **stdin/stdout** rather than a literal filename. Simply running `cat -` would hang waiting for your keyboard input.

To read a file named `-`, you need to explicitly give the shell a path to it:

- `./-` tells the shell "the file named `-` in the current directory" — not stdin.

## Commands Used

- `ls` — list files in the current directory
- `cat ./-` — read the file named `-` from the current directory

# Solution

1. Log in with the Level 0 password.
2. Run `ls` — you will see a file named `-`.
3. Read it using: `cat ./-`
4. The output is the password for Level 2.
